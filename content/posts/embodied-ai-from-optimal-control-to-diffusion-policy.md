作为一个从材料学转向机器人算法的博士新生，我最近开始系统学习具身智能的基础知识。这篇文章记录了我从最优控制到扩散策略的学习路径，适合同样零基础转行机器人领域的同学参考。

## 为什么从最优控制开始

很多人直接跳到强化学习或模仿学习，但跳过了一个关键前提——**机器人控制到底在做什么**。最优控制（Optimal Control）是理解一切控制算法的根基。

核心思想很简单：在约束条件下，找到让某个目标函数最小的控制策略。三要素缺一不可——系统模型 f(x,u)、代价函数 J、优化求解。

### LQR：线性系统的解析最优

LQR（Linear Quadratic Regulator）适用于线性时不变系统，通过求解 Riccati 方程得到最优反馈增益矩阵：

- 目标：最小化二次型代价函数 J = ∫(xᵀQx + uᵀRu)dt
- 最优控制律：u = -Kx，其中 K = R⁻¹BᵀP
- P 由代数 Riccati 方程求解：AᵀP + PA - PBR⁻¹BᵀP + Q = 0

特点是闭环稳定、离线计算、简单高效，适合线性化后的局部控制，比如平衡控制、姿态稳定。

### MPC：滚动时域的在线优化

MPC（Model Predictive Control）更灵活但计算量更大：

- 每个控制周期求解一个有限时域内的开环最优控制问题
- 只执行第一步控制量，下一周期重新优化（滚动时域）
- 可显式处理状态/输入约束（如关节限位、力矩上限）
- 可处理非线性动力学模型

### LQR vs MPC 对比

| 特性 | LQR | MPC |
|------|-----|-----|
| 求解方式 | 解析解（Riccati） | 数值优化（QP/NLP） |
| 计算时机 | 离线一次 | 在线每步求解 |
| 约束处理 | 不支持 | 显式支持 |
| 非线性 | 需线性化 | 直接处理 |
| 典型应用 | 平衡控制、姿态稳定 | 轨迹跟踪、全身控制 |

理解了这个框架，后面看强化学习的 reward 设计、Diffusion Policy 的动作生成，都会有"原来如此"的感觉——RL 的 reward 对应最优控制的负代价函数，RL 的 transition 对应系统模型 f(x,u)。

## 扩散模型：DDPM vs DDIM

Diffusion Policy 是当前具身智能最重要的策略架构之一，而要理解它，必须先搞懂扩散模型的两个核心变体：DDPM 和 DDIM。

### DDPM：老实人一步步去噪

DDPM（Denoising Diffusion Probabilistic Model）是原始方法：

- 前向过程：马尔可夫链逐步加噪 q(xₜ|xₜ₋₁)
- 反向过程：学习去噪 p_θ(xₜ₋₁|xₜ)，需逐步采样
- 从纯噪声开始，每一步预测去噪方向并加随机噪声
- 跑 1000 步才出图，因为马尔可夫链不能跳步

### DDIM：聪明人跳着去噪

DDIM（Denoising Diffusion Implicit Model）是 DDPM 作者自己提出的改进：

- 去掉随机噪声，变成确定性映射
- 非马尔可夫前向过程，x_t 可以直接从 x_0 算，不依赖中间步
- 1000 步压缩到 20-50 步，速度快 20-50 倍
- 同一个输入噪声，每次结果完全一样

### 为什么对机器人控制至关重要

Diffusion Policy 在机器人控制里要**实时推理**——机器人每秒要输出好几次动作。如果用 DDPM 的 1000 步采样，根本跑不快。所以实际部署时：

- 训练：用 DDPM 的训练目标（预测噪声）
- 推理：用 DDIM 的跳步采样（50 步甚至更少）

而且 DDIM 的确定性带来额外好处——**可复现**。调试策略时，同一个观测输入每次得到相同的动作，方便排查问题。

| | DDPM | DDIM |
|---|---|---|
| 训练方式 | 一样 | 完全一样 |
| 采样步数 | ~1000 | 20-50 |
| 能否跳步 | 不能 | 能 |
| 随机性 | 每步加噪声 | 不加噪声 |
| 同输入结果 | 每次不同 | 每次相同 |

## Mobile ALOHA：低成本移动操作的代表

Mobile ALOHA 是 Stanford 2024 年的工作，在固定双臂系统 ALOHA 基础上加了移动底盘，让机器人可以边走边干活——炒菜、开柜子、倒水、收拾桌面。

### 硬件系统

| 部件 | 配置 | 作用 |
|---|---|---|
| 移动底盘 | AgileX Tracer 差分驱动 | 全向移动，最高 1m/s |
| 双臂 | ViperX 300 × 2，各 6-DOF | 抓取和操作 |
| 相机 | 顶部 2 个 + 手腕 2 个 | 视觉观测输入 |
| 计算 | GPU 笔记本 | 实时推理策略 |

关键优势是便宜——总成本约 $32k，而商业移动操作平台通常 >$100k。

### 数据采集：Leader-Follower 遥操作

人穿戴 Leader 双臂（没有电机，只有编码器记录角度），机器人的 Follower 臂实时跟随。全程记录（相机图像, 动作）数据对。每个任务收集 50 条演示。

### 核心创新：Co-training

注意：ACT（Action Chunking with Transformers）是原始 ALOHA 论文（2023）提出的，不是 Mobile ALOHA 的原创。Mobile ALOHA 真正的贡献是 **Co-training 混合训练**。

问题很直接：移动操作任务复杂，50 条演示不够学好。但他们发现：

- 静态 ALOHA 数据：820 条（固定桌面双臂上采集，没有移动）
- 移动 ALOHA 数据：50 条/任务
- 混合在一起训练

效果惊人——平均成功率从约 15% 跳到约 85%。静态数据教会了策略"怎么抓东西"，移动数据教会了"怎么走到目标旁边"，两个能力叠加。

### 和 UMI 的对比

UMI（Universal Manipulation Interface）也是 Stanford 2024 年初的工作，但走了完全不同的路线：

| | UMI | Mobile ALOHA |
|---|---|---|
| 数据采集 | 手持夹爪，无需机器人 | 必须用机器人 Leader-Follower |
| 策略 | Diffusion Policy | ACT |
| 核心创新 | 采集设备 + world-to-robot 推理 | Co-training 混合训练 |
| 数据扩展性 | 高——任何人手持就能采 | 低——必须买特定机器人 |
| 部署能力 | 固定臂操作 | 移动双臂全屋操作 |

两者是平行路线，解决不同维度的问题，不存在简单的"谁更好"。

## 10 篇核心论文学习路线

一个专业朋友推荐了 10 篇具身智能标志性论文，我的结论是**不需要每篇都复现**，正确策略是分层投入。

### 两条技术路线

| | 扩散策略路线 | VLM 大模型路线 |
|---|---|---|
| 核心思想 | 用扩散/流匹配模型表示动作分布 | 用预训练大语言模型做策略 |
| 演进线 | Diffusion Policy → RDT → Pi0 | RT-2 → Open-X → OpenVLA → GR00T |
| 优势 | 动作精度高，多模态好 | 语言理解强，泛化好 |
| 劣势 | 推理慢 | 动作精度低，模型大 |

另外 UMI / Mobile ALOHA 不属于策略路线，是解决"数据从哪来"的硬件/采集方案。

### 三层学习策略

**第一层（了解思想）**：Diffusion Policy、UMI、Mobile ALOHA、RT-2、Open-X。看 intro + 核心方法图，花 30 分钟搞懂"解决了什么问题、用了什么思路"就够了。

**第二层（精读+跑代码）**：OpenVLA、RDT。读完整论文，跑通官方 demo。OpenVLA 是开源 VLA 里复现门槛最低的，RDT 是扩散策略大规模化的代表。

**第三层（重点跟踪）**：Pi0 系列、GR00T、Generalist Gen-0。当前 SOTA 和未来方向，现阶段跟踪进展就行，等基础扎实后再深入。

## 小结

从最优控制到扩散策略，具身智能的技术栈看起来很深，但底层逻辑是连贯的：

1. 最优控制定义了"什么是好的控制"
2. 强化学习在模型/代价未知时用数据逼近最优控制
3. 模仿学习用人类演示替代试错
4. 扩散策略用 DDIM 加速让模仿学习可以实时部署

下一步我会精读 Diffusion Policy 论文，然后从 OpenVLA 或 Pi0 选一个深入。如果你也在转行机器人，建议先把 LQR 和扩散模型的基础打牢，后面的论文会读得顺畅很多。
